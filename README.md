# 🧠 Quiz Website

An interactive and responsive quiz website designed to provide a simple and engaging way for users to test their knowledge through multiple-choice questions.

## ✨ Features

* 📝 Multiple-choice quiz questions
* 🎯 Interactive quiz experience
* 📊 Score/result display
* 🔄 Easy quiz navigation
* 📱 Fully responsive design
* 🎨 Clean and user-friendly interface
* ⚡ Fast and lightweight website

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Responsive Design
* Media Queries

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/janvi-jain/quiz-website.git
```

### Open the Project

```bash
cd quiz-website
```

Open the project in VS Code.

### Run the Website

If it is a Vite/React project:

```bash
npm install
npm run dev
```

If it is a simple HTML/CSS/JavaScript project, open `index.html` using Live Server.

## 🎯 Project Purpose

The purpose of this project is to create an interactive quiz platform while practicing frontend development concepts such as responsive layouts, user interactions, JavaScript functionality, and Bootstrap components.

## 📱 Responsive Design

The website is designed to work across:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile
